# Vis Platform｜MVP 架构评审单页

**产品定位：** 面向生命科学与临床研究，提供「自然语言驱动 + 专业参数微调」的零代码出版级科研作图平台，弥合数据分析与顶刊发表之间的可视化鸿沟。

**评审性质：** MVP 架构与工程边界评审。以下按叙事顺序列出结论与待决事项。

---

## 一、 解法范式：描述 - 生成 - 精修

把作图从写代码变成提要求，同时不牺牲专业度与可复现性。

| 步骤 | 用户动作 | 系统动作 |
| :--- | :--- | :--- |
| **STEP 1 描述意图** | 用科研语言说明想展示什么，不记 R 语法 | 解析科研意图与变量语义 |
| **STEP 2 自动生成** | 确认关键歧义（仅在必要时） | 发现数据、选择方法、产出首版专业图 |
| **STEP 3 精修沉淀** | 语言或面板微调 | 每次变更生成不可变版本 |

**设计约束：** 只问工具与上下文无法安全解决的问题；目标一次交互补齐上下文、三次交互内出图；内部 agent 协调过程对用户隐藏。

---

## 二、 四大科研工作场景（一源多视口）

覆盖从**单点打磨**到**成果汇报**的完整科研生命周期：

| 界面 | 核心场景 | 关键能力 |
| :--- | :--- | :--- |
| **Workspace 单图精修** | 集中把一张核心图做好 | 自然语言出图 + 面板微调 + 时间轴历史（撤销 / 还原） |
| **Canvas 分支探索** | 同一份数据对比多种统计假设 | 二维无限画布、同源平行出图、分支状态互相隔离 |
| **Report 学术叙事** | 图表与论文正文有机结合 | 章节树图文协同、段内原地指令增量生图 |
| **Slides 演讲汇报** | 成果宣讲、组会或学术交流 | 16:9 卡槽自动排版、演讲者模式与备注 |

**贯穿机制 · Figure Link 指针：** 下游引用的是版本指针而非静态截图，支持「跟随最新」与「定稿锁定」。

### 图 02 · 数据内核：三层解耦与版本血缘
![02-conceptual-data-model](assets/02-conceptual-data-model.svg)
- **`Dataset`（只读 + Agent-friendly Profile）**：提取精炼数据画像（变量语义、观测单元、分布与缺失率），模型只读几十行元数据即可推理，省 Token 且避免原始数据出域；
- **`AnalysisResult`（统计中间态 · 核心创新）**：解耦重度统计拟合与视觉渲染，改颜色 / 调尺寸直接复用结果，**0 重算**；仅更换统计假设才重新触发计算；
- **`PlotVersion`（不可变图版本）**：绑定视觉参数、多格式产物与可复现证据链（R 源码、随机种子、图注）；
- **`VersionGraph`**：在 Workspace 展开为线性时间轴，在 Canvas 展开为二维分支树；
- **`FigureLink`**：跨端引用指针，模式 A 跟随最新 / 模式 B 定稿锁定。

### 图 03 · 运行链路：Agent 编排与受限 R 沙箱
![03-agent-orchestration](assets/03-agent-orchestration.svg)
- **统一管线**：请求入口 -> 意图 Agent -> 数据 Agent -> 绘图 Agent -> 受限 R 沙箱 -> 不可变版本，四界面共用，无孤岛后端；
- **缓存直通**：数据 Agent 检查 `AnalysisResult`，纯外观修改跳过统计计算；
- **稳健性**：沙箱 renv 隔离、禁止外联、读写与资源受限；报错自动反思修复最多 3 次；**失败不覆盖上一版**；
- **边界**：Report / Slides 的排版与段落指令直接操作文档树，不进入绘图管线。

### 图 04 · 平台接入与三步试点路线
![04-platform-integration](assets/04-platform-integration.svg)

**赋能原则**：不改动现有平台底层库，标准契约接入，单点闭环验证。

已定义标准化的 `Source Contract`（数据源提供方规范）：平台只需暴露对象读取 API，适配层负责归一化数据集描述并提取 Agent 精简画像；成果以高清图 + R 源码 + 可复现指纹回传。

| 步骤 | 目标 | 交付 |
| :--- | :--- | :--- |
| **STEP 1 选定单点突破口** | 选定高频分析模块 | 对齐对象 schema 与读取接口 |
| **STEP 2 打通单图闭环** | 结果旁增加作图入口 | 调起 Workspace 完成精修 |
| **STEP 3 闭环回传与扩展** | 资产回写与按需延伸 | 图表与可复现指纹回传 |
